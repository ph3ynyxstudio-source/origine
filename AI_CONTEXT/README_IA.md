# Contexte IA — Lun4rMood

Lun4rMood est une application d’introspection émotionnelle simple, mobile-first et local-first.

Le but n’est pas de créer une application médicale, thérapeutique ou diagnostique.

Le cœur du projet         :
- suivre ses émotions
- suivre son énergie
- suivre certains moments de la journée
- observer ses tendances personnelles
- aider l’utilisateur à mieux se comprendre

Lun4rMood doit rester :
- simple
- stable
- doux
- privé
- rapide
- utilisable sans friction

Avant toute modification, consulter :
- STYLE_GUIDE.md
- UI_UX_BOOKMARKS.md
- RULES_MVP.md

Règle importante :
Toute modification UI/UX notable doit être documentée dans UI_UX_BOOKMARKS.md.

Ne pas réinventer l’identité visuelle.
Ne pas ajouter de complexité sans demande explicite.
Corriger uniquement ce qui est demandé.
