# Style Guide — Lun4rMood

## Direction visuelle

Lun4rMood doit avoir une ambiance :
- nocturne
- douce
- introspective
- lunaire
- calme
- légèrement mystique, sans excès fantasy

## Palette principale

Fond :
- bleu nuit très sombre
- noir bleuté

Accents :
- mauve
- cyan doux
- rose lunaire subtil

Texte :
- blanc doux
- gris bleuté pour le texte secondaire

## UI

L’interface doit rester :
- lisible sur mobile
- espacée
- calme
- sans surcharge
- sans animations agressives

## Éléments visuels importants

À préserver :
- ambiance lunaire
- cartes sombres
- effets glow subtils
- lisibilité mobile
- navigation simple
- sensation de journal intime numérique

À éviter :
- néon trop agressif
- interface trop gaming
- surcharge de cartes
- dashboards complexes
- langage médical
- fonctionnalités sociales
