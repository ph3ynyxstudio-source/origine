# LunarMood Mobile Assets

Expo reads the production assets directly from this folder:

- `icon.png`
- `adaptive-icon.png`
- `splash-icon.png`

Use the subfolders as working storage for source and organized exports.

- `logo/`: app logos and transparent brand marks.
- `backgrounds/`: welcome and app background images.
- `moons/`: moon phase icons.
- `store/`: Play Store and marketing exports.
- `source/`: large masters kept for future exports.
